# Vibe Mart 🛒

Vibe Mart is a modern and user-friendly e-commerce website designed to make online shopping simple, fast, and convenient. Customers can browse products, view details, add items to their cart, and enjoy a smooth shopping experience.

## ✨ Features

* 🛍️ Browse products easily
* 🔎 Search and explore products
* 📂 Product categories
* 🛒 Add products to cart
* 💳 Simple checkout experience
* 🎁 Attractive offers and discounts
* 📱 Responsive design for mobile and desktop
* 🎨 Clean and modern user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📁 Project Structure

```text
Vibe-Mart/
```

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Start browsing Vibe Mart.

## 🎯 Purpose

The main purpose of Vibe Mart is to provide customers with a simple and enjoyable online shopping platform where they can discover and purchase products conveniently.
